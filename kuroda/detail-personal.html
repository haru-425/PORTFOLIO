作品説明

CurryEngineは、開発効率の向上を目指して設計されたゲームエンジンです。ホットリロード機能やC#スクリプティングなど、開発者が素早くゲームを作り上げるための機能を多数実装しています。現在も開発中で、今後さらに機能を追加し、より多くの開発者にとって使いやすいエンジンを目指しています。

View Code on GitHub

実装技術

  • HLSLシェーダーのホットリロード: シェーダーコードの変更をリアルタイムで反映させる機能を実装しました。これにより、開発者はシェーダーの調整を素早く行うことができ、開発効率が大幅に向上します。
  • C#スクリプティング: ホットリロードにも対応し、ゲームのロジックを素早く実装できます。
  • 描画負荷の最適化: カリングなどの最適化を行い、より低スペックな環境でも快適に動作するように改善しています。

改善目標

現状、描画負荷が高いため、カリングなどの最適化を行い、より低スペックな環境でも動作するように改善したいと考えています。
